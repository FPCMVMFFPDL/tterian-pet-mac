# LOTRI_PET — 자유 배치형 데스크톱 펫

## 실행
1. Node.js(LTS)를 설치합니다: https://nodejs.org
2. 이 폴더에서 터미널을 열고 `npm install` (처음 한 번만)
3. `npm start`
4. 작업표시줄 오른쪽 아래 트레이 아이콘에서 캐릭터를 켜고 끄거나 종료할 수 있습니다.

## 현재 동작
- 캐릭터를 마우스로 드래그해 원하는 위치에 둘 수 있습니다. 위치는 캐릭터별로 자동 저장됩니다. 걷기/날아가기 동작은 제거했습니다.
- 왼쪽 클릭: 짧은 통통 튀기 반응 + 말풍선
- 캐릭터 위에서 오른쪽 클릭: 사이드 추천, 오늘의 간식 운세, 쓰다듬기, 재우기/깨우기, 숨기기
- 가만히 있을 때 눈 깜빡임/앉기/잠자기 등 가벼운 대기 모션
- 현재 사이드 추천은 데모용 예시 목록입니다. 실제 제안/배포 전에는 롯데리아의 공식 메뉴와 판매 여부를 확인해 주세요.

## 레이아웃 수정
- `index.html` 상단의 `:root` CSS 변수에서 말풍선/우클릭 메뉴의 배경색, 글자색, 테두리색, 모서리, 글자 크기를 바꿀 수 있습니다.
- 같은 파일에서 `.bub`, `#menu`, `#menu button` 스타일을 수정하면 말풍선과 메뉴의 크기·여백·정렬 등을 바꿀 수 있습니다.
- `main.js`는 캐릭터 동작을 담당합니다. 화면 디자인을 바꾸려면 우선 `index.html`만 수정하는 것을 추천합니다.

## 캐릭터 이미지 준비
각 캐릭터 폴더 안에 아래 PNG를 넣으면 임시 도형 대신 이미지가 표시됩니다.

- `idle/idle_01.png`, `idle_02.png` … : 기본 대기 모션 (눈 깜빡임/호흡 등)
- `sit/sit_01.png`, `sit_02.png` … : 앉아서 쉬기
- `sleep/sleep_01.png`, `sleep_02.png` … : 잠자기
- `click/click_01.png`, `click_02.png` … : 클릭 반응 (놀라기/뽀용 튀기)

선택 사항: `shared/bubble.png`(말풍선 배경), `shared/chair.png`(의자 이미지). 고정형 간단 버전에서는 의자 이미지는 필수가 아닙니다.

## 이미지 규격
- 투명 배경 PNG
- 프레임마다 동일한 캔버스 크기 권장: 400×400px
- 캐릭터의 바닥/발 위치를 모든 이미지에서 동일하게 유지 (기본 기준은 캔버스 높이의 약 89%, 400px이면 y=356px)
- 캐릭터는 오른쪽을 바라보게 그리면 왼쪽 방향은 자동 반전됩니다.
- 파일명은 영문 소문자 + 두 자리 번호: `idle_01.png`, `idle_02.png` 등
- 각 캐릭터의 이름/색상/크기/말풍선 대사는 `character.json`에서 수정합니다.

## 캐릭터 3종
- `characters/char_01/`
- `characters/char_02/`
- `characters/char_03/`

각 폴더에 이미지를 같은 방식으로 넣으면 됩니다. 이미지가 없는 상태에서는 테스트용 임시 도형이 표시됩니다.

## 추가 기능
- 캐릭터 위에 마우스를 올리면 왼쪽 위에 크기 조절 버튼(↗)이 표시됩니다. 버튼을 누른 채 위아래로 움직여 크기를 조절할 수 있습니다.
- 기본 대기 숨쉬기는 발 위치를 기준으로 세로 크기 변화만 적용합니다.
- 각 캐릭터의 `typing` 폴더에 `typing_01.png`, `typing_02.png` 등을 넣으면 우클릭 메뉴의 `타자 모션 켜기/끄기`로 테스트할 수 있습니다. 이 기본 데모는 다른 앱에서 키보드를 치는 것을 전역 감지하지는 않습니다.


## 타자 모션
각 캐릭터의 `typing` 폴더에 `typing_01.png`, `typing_02.png` 등의 투명 PNG를 넣으면 키보드 입력 중 해당 이미지가 번갈아 표시됩니다. 전역 키보드 입력 감지를 위해 `npm install`로 `uiohook-napi` 의존성을 설치해야 합니다. Electron 버전에 따라 네이티브 모듈 재빌드가 필요할 수 있습니다.
